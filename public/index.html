Questions, answered

What does the line actually do?

It finds the agents on your machine (or just the ones you chose with --to), installs any runtime a server needs (Node.js, uv), registers each MCP server with every agent using that agent's own CLI where it has one (claude mcp add, codex mcp add, gemini mcp add, code --add-mcp) and merges JSON config for the rest (~/.cursor/mcp.json). Skills install through the open skills CLI from skills.sh, globally, into every agent you kit.

Does it install the agents themselves?

No. Kit'Em! kits the agents you already have. Install them first (or grab them with Get'Em!), then run your line. Agents installed later get kitted the next time you run it.

Is it safe?

The script is plain bash you can read before running it: hit “View script”, or add --dry-run to print every action without changing anything. Remote servers are just URLs; nothing is sent anywhere until you sign in to them from your agent. Skills are instructions your agent follows, so skim the ones you add.

Where do tokens and API keys go?

Never in the line, the share link or the script. Servers marked oauth open a sign-in the first time your agent uses them, and the agent keeps the credentials. Kit'Em! never sees them.

What's “Route through Docker MCP Gateway”?

Servers that exist in the Docker MCP Catalog are enabled in Docker's gateway and run in containers, and each agent gets one MCP_DOCKER entry instead of many. Fewer configs to keep in sync, servers isolated from your machine. It needs Docker Desktop with the MCP Toolkit; servers that aren't in the catalog are still wired directly.

Does re-running it duplicate things?

No. Every step checks first: servers an agent already has are skipped and skills already on disk are left alone, so only what's missing is added. Add --update to re-install the skills you picked at their latest version.

How do I remove something?

Use the agent's own command: claude mcp remove playwright -s user, codex mcp remove playwright, gemini mcp remove -s user playwright. For Cursor and VS Code delete the entry from their mcp.json. Skills: npx skills remove -g tdd.

How were the skills picked?

High signal over volume: from the skills.sh leaderboard, the repos most recommended across 2026 roundups (Anthropic, obra/superpowers, Matt Pocock, Vercel, Addy Osmani, OpenAI) and hand-picked community repos like Helmcode's. Clones and look-alike forks are left out. Install counts come from skills.sh and refresh daily, and a check runs against every repo to confirm each skill exists.

Can I share my setup?

Yes. “Copy link” encodes your selection in the URL, and anyone who opens it gets the same picks and the same line. “Download .sh” gives you a script with the picks baked in that works without this site.
