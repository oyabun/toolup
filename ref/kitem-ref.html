Questions, answered

What does the command actually do?

It finds the agents on your machine (or just the ones you chose), installs any runtime a server needs (Node, uv), registers each MCP server with every agent using that agent's own CLI where it has one (claude mcp add, codex mcp add, gemini mcp add, code --add-mcp) and merges JSON config for the rest (~/.cursor/mcp.json). Skills install through the open skills CLI from skills.sh, globally, into every agent you kit.

Does it install the agents themselves?

No — Kit'Em! kits the agents you already have. Install them first (or grab them with Get'Em!), then run your line. Agents installed later get kitted the next time you run it.

How were the skills picked?

From the skills.sh leaderboard, the repos most recommended across 2026 roundups (Anthropic, obra/superpowers, Matt Pocock, Vercel, Addy Osmani, OpenAI) and hand-picked community repos like Helmcode's. Install counts come from skills.sh. Every skill was checked to exist in its repo.

Is it safe?

The script is plain bash you can read before running — hit “View script”. Remote servers are just URLs; nothing is sent anywhere until you sign in to them from your agent. Add --dry-run to print every action without changing anything.

Where do tokens and API keys go?

Nowhere in the command. Remote servers marked oauth ask you to sign in the first time your agent uses them. Kit'Em! never puts secrets in the command or the share link.

What's “Route through Docker MCP Gateway”?

Servers that exist in the Docker MCP Catalog are enabled in Docker's gateway and run in containers, and each agent gets one MCP_DOCKER entry instead of many. Fewer configs to keep in sync, servers isolated from your machine. Servers not in the catalog are still wired directly.

Does re-running it duplicate things?

No. Every step checks first: servers already registered with an agent are skipped, skills already present are left alone.

How do I remove a server?

Use the agent's own command, e.g. claude mcp remove playwright -s user, codex mcp remove playwright, or delete the entry from ~/.cursor/mcp.json.

Can I share my setup with my team?

Yes — “Copy link” encodes your selection in the URL. Anyone who opens it gets the same picks and the same command.
